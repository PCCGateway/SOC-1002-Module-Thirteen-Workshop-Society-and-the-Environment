# The Environment & Society — Sociology Investigation

A single-page student activity designed for GitHub Pages.

## Student tasks
1. Environmental sociology warm-up
2. Zoom In / Zoom Out analysis
3. Apply Functionalism, Conflict Theory, and Symbolic Interactionism
4. Find and evaluate a current news article
5. Build a sociological case study from the article
6. Write a final sociological claim

## Features
- Auto-saves in the current browser
- **Save My Work** downloads a JSON progress file so students can move between lab computers
- **Load Saved Work** restores that JSON file on another computer/browser
- Print / Save as PDF
- Submission Summary compiles student responses
- No external libraries required

## Publish with GitHub Pages
Upload `index.html` to a repository. In repository Settings > Pages, deploy from the branch containing the file. The activity will run as a static site.
